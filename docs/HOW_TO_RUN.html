How to run this framework

Agentic QA Automation Framework — Automation Exercise. Stack: Java 21 · Selenium · TestNG · REST Assured · Extent Reports. Markdown twin: HOW_TO_RUN.md at the repo root.

Setup mvn test Reports Skills & coding agents LLM AgentCli Validators What to expect

0. One-time setup

cd agentic-qa-automation-framework
cp .env.example .env
mvn -DskipTests dependency:resolve
mvn -DskipTests compile test-compile

Need JDK 21+, Maven 3.9+, and Chrome (or Firefox/Edge). LLM keys in .env are only for optional AgentCli.

Default mode: single-threaded + headed browser (you will see Chrome). Override with -DHEADLESS=true / -DPARALLEL=true.

1. Run tests with Maven

Full suite

mvn test

By TestNG group

mvn test -Dgroups=smoke
mvn test -Dgroups=ui
mvn test -Dgroups=api
mvn test -Dgroups=integration
mvn test -Dgroups=unit
mvn test -Dgroups=regression

Headless / parallel

mvn test -DHEADLESS=true
mvn test -DPARALLEL=true
mvn test -DPARALLEL=true -DTHREAD_COUNT=4 -DHEADLESS=true

Single class / method

mvn test -Dtest=SignupUiTest
mvn test -Dtest=ProductListApiTest#shouldReturnProductCatalogue
mvn test -Dtest=CheckoutUiTest -DHEADLESS=true

2. Where to see the report

Primary report is Extent HTML (generated after mvn test):

target/extent-report/index.html

scripts/extent-report/open.sh
# or
open target/extent-report/index.html
ArtifactLocationWhen
Extent report target/extent-report/index.html After any mvn test
Screenshots / failure text target/artifacts/ UI failures
JaCoCo coverage target/site/jacoco/index.html After mvn verify

In Extent you will see test names, steps, API request/response attachments (secrets redacted), and screenshots when UI tests fail.

The report opens automatically when the suite finishes. Disable with -DOPEN_REPORT=false. AgentCli full / execute also auto-opens 11-execution-report.html.

3. Coding agents & skills (Cursor / Claude / Copilot)

Skills and agent role files guide the IDE agent. They do not call OpenAI / Claude / DeepSeek APIs by themselves.

How to run

  1. Open the repo in Cursor (or Claude Code / Copilot Chat).
  2. Ask the agent to follow a skill or role, for example:
    • “Follow .ai/skills/agentic-delivery-chain/SKILL.md for Contact Us”
    • “Act as .ai/agents/agentic-delivery-orchestrator.md”
  3. Or use Cursor commands: /analyze-requirement, /create-ui-test, /create-api-test, /validate-contribution.

4. Runtime LLM agents (AgentCli)

Optional pipeline that calls paid APIs. Keys live in local .env only. This is not required for mvn test.

Cheapest verified models (cost-first — see DECISIONS ADR-006)

RoleProviderModel
Requirement + test-case generationOpenAI (GPT)gpt-5.4-nano
Reviewer + UI/API automatorsAnthropic (Claude)claude-haiku-4-5
Report analysisDeepSeekdeepseek-flash
Executor / email—Maven / SES (no LLM)

Commands

# Analyze → cases → review
mvn -q -DskipTests exec:java -Dexec.mainClass=com.agenticqa.agents.AgentCli \
  -Dexec.args="analyze --requirement docs/examples/sample-requirement.md"

# Full pipeline (includes smoke execution)
mvn -q -DskipTests exec:java -Dexec.mainClass=com.agenticqa.agents.AgentCli \
  -Dexec.args="full --requirement docs/examples/sample-requirement.md --groups smoke"

# Execute + report only
mvn -q -DskipTests exec:java -Dexec.mainClass=com.agenticqa.agents.AgentCli \
  -Dexec.args="execute --groups smoke"

What to expect

  • Console: Agent pipeline complete. Output: …
  • Markdown / logs under agent-generated/runs/run-<timestamp>/
  • After full / execute: simple pass/fail HTML at …/11-execution-report.html (console also prints Execution HTML report: …)
  • Maven Extent report still at target/extent-report/index.html
  • Draft Java (if automators ran) under agent-generated/src/…
  • Drafts are untrusted until AgentValidator + human promotion into src/
