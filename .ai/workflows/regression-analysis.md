# Regression Analysis Workflow

1. Inspect changed files
2. Compare to `.ai/knowledge/automation-inventory.md`
3. Identify impacted pages/clients/factories/tests
4. Map to TestNG groups (`smoke`, `ui`, `api`, `regression`)
5. Recommend smoke + regression scenarios (depth over breadth)
6. Generate impact report — no fabricated results
